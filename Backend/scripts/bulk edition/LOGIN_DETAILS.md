# Bulk Edition Login Details

This file describes the login records generated by the bulk seed edition.

All seeded accounts use the same development password by default:

`SmartCredit@123`

You can override that password with `SEED_DEFAULT_PASSWORD` before running the
seed.

## Generated bulk accounts

The bulk seed creates additional lender and borrower accounts with deterministic
IDs and emails based on the configured batch ID:

- `seed_<batchId>_lender_<NNNNNN>`
- `seed_<batchId>_borrower_<NNNNNN>`
- `lender.<batchId>.<NNNNNN>@seed.smartcredit.lk`
- `borrower.<batchId>.<NNNNNN>@seed.smartcredit.lk`

Example with the default batch ID `bulk_dev`:

- `seed_bulk_dev_lender_000001`
- `seed_bulk_dev_borrower_000001`
- `lender.bulk_dev.000001@seed.smartcredit.lk`
- `borrower.bulk_dev.000001@seed.smartcredit.lk`

The bulk login file generated by the script includes the role, user ID, email,
phone number, password, account status, and KYC status for every seeded user.
