# Basic Edition Login Details

This file documents the stable development accounts generated by the basic seed
edition.

All generated accounts use the same development password by default:

`SmartCredit@123`

You can override that password with `BASIC_SEED_DEFAULT_PASSWORD` before running
the seed.

## What this edition generates

The basic seed keeps a small development dataset, but the same login-password
rule applies to any generated lender or borrower accounts:

- `users` records are written for each account
- `authCredentials` records store the shared password hash
- the login endpoint accepts the email and password above

If you need the bulk-generated accounts, use the bulk edition login file
instead.
